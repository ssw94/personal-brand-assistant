# Personal Brand AI — Feature Matrix

This matrix defines intended capability/entitlement boundaries. It is not a claim that the current repository has implemented them; current status is in `docs/gap-analysis.md`.

| Capability | Free | Creator | Pro | Expert | Team |
|---|---|---|---|---|---|
| Professional profile and memory | Included | Included | Included | Included | Included |
| Resume builder and career foundation | Included | Included | Included | Included | Included |
| AI LinkedIn post generation | 3 posts/month | 15 posts/month | 30 posts/month | 60 posts/month | Custom usage |
| Content ideas and pillars | Core | Included | Included | Included | Shared/team controls |
| Writing style and strategy | Core | Included | Included | Included | Shared/team controls |
| AI critique and revision | Core | Included | Included | Included | Included |
| Research/context | Limited/core | Included | Included | Included | Included |
| Calendar and scheduling | Not included unless explicitly enabled | Included | Included | Included | Included |
| LinkedIn publishing | Not included | Provider-dependent | Provider-dependent | Provider-dependent | Provider-dependent |
| Analytics | Basic/eligible data only | Included | Included | Included | Included |
| Analytics intelligence | Not included | Core insights | Advanced insights | Advanced insights | Shared insights |
| Advanced career workflows | Core | Core | Included | Included | Included |
| Team workspace | Not included | Not included | Not included | Not included | Included |

“Provider-dependent” means an approved account connection and healthy official API are required. All rows are enforced server-side through entitlements; frontend visibility is only a convenience.
