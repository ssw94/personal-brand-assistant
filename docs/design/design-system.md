# Personal Brand AI — Design System

## Visual direction

Premium modern AI SaaS for software engineers and technology professionals: spacious, professional, intelligent, clean, approachable, and calm. The approved UX/product designs are the visual source of truth.

## Foundation

- Material UI is the primary component system.
- One centralized MUI theme owns palette, typography, spacing, radius, elevation, breakpoints, variants, focus states, and component defaults.
- Use MUI primitives before creating custom components: AppBar, Drawer, Card, Stack, Grid, TextField, Select, Autocomplete, Chip, Alert, Dialog, Tabs, Tooltip, Avatar, progress indicators, and approved data/date components.
- Use one icon family consistently; icons should clarify actions, not decorate every surface.

## Identity

Use a restrained indigo-led palette with neutral surfaces, readable dark text, muted secondary text, and semantic success/warning/error states. Avoid excessive gradients, random colors, excessive borders, dense enterprise tables, and excessive animation.

## Components and states

Reusable primitives should exist for page headers, cards, buttons, inputs, badges, navigation, empty states, loading states, error states, feedback/snackbars, avatars, post previews, status chips, analytics cards, and dialogs. Every async workflow needs idle, loading, success, and failure states with contextual messaging.

## Layout

Desktop-first authenticated layouts use a professional sidebar and clear page header. Content uses generous whitespace, consistent grid/stack spacing, restrained card grouping, and a clear primary action. Responsive behavior must preserve hierarchy and touch target quality on smaller screens.
