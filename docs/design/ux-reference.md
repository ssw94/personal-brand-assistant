# Personal Brand AI — UX Reference

The approved UX/product designs supplied for this repository are the visual source of truth. Existing implementation, generic SaaS patterns, and default MUI appearances are not design references when they conflict with the approved designs.

## Required qualities

- Premium modern AI SaaS
- Clean professional B2B SaaS aesthetic
- Strong hierarchy and readable typography
- Refined cards, subtle borders, and restrained elevation
- Professional sidebar/navigation
- Consistent controls, spacing, radius, and iconography
- No generic admin-dashboard appearance
- No arbitrary Tailwind/shadcn component language competing with MUI

## Audit rule

Before accepting a page, compare it to the approved reference: page structure, hierarchy, spacing, button treatment, card density, empty/loading/error states, responsive behavior, and copy tone. If a reference image or product decision is ambiguous, document the question under `docs/design/` or `docs/product/` rather than inventing behavior.
